# Mekari product terminology

### Mekari One product terminology

| Term               | Definition                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------- |
| Feature            | A module or key activity listed in main navigation. Primary value proposition of an app.    |
| Subfeature         | Specific activities or functions within a feature.                                          |
| Menu               | The navigation section displaying features (sidebar or top bar). Not the same as "feature". |
| Add-on             | Any installed third-party app (integration) or additional Mekari feature.                   |
| Integration        | All third-party applications, including sold Mekari products available to be integrated.    |
| Additional feature | All Mekari features not included in the base subscription package.                          |
| Package            | A set of subscription plans.                                                                |
| Additional quota   | Allocated limits beyond the package that users can purchase.                                |
| Service            | Collective offerings: packages, add-ons, quotas, training, etc.                             |

Table entries are capitalized as table convention — that does not make them proper nouns. In running
copy they follow sentence case and the parenthetical rule in [sentence case](formatting.md).

### Critical term usage

| Use                                     | Never use                       |
| --------------------------------------- | ------------------------------- |
| Sign in (verb) / sign-in (noun)         | login                           |
| Sign out (verb) / sign-out (noun)       | logout                          |
| Set up (verb) / setup (noun)            | set-up                          |
| Customer (the end user an agent serves) | user                            |
| You / Anda / Você                       | "we" when referring to the user |

### Standard input labels

Use verbatim. Do not paraphrase or localize unless a translation has been approved.

Full name, Company name, Email, Phone number, Password, Industry, Number of employees, Occupation,
Province, City, Kabupaten, District (Kecamatan), Kelurahan

> **PT-BR note:** these have not been formally localized for PT-BR. Use the closest natural Brazilian
> Portuguese equivalent and flag for native-speaker review before shipping.

### Mekari One navigation labels

Account settings, Company info, Company list, Change language, Switch account, Notifications,
Switch app, Universal search, Sign out

translated, use as-is until a localized version is approved.
